# 博客功能全览

这篇文章把本站目前支持的所有内容能力一次说清楚：从一个个人博客的缘起，到正文排版、拼音注音、响应式目录、工具嵌入四大块，逐项列全。

## 一、正文排版：MDX 全语法

正文基于 MDX，以下语法全部可用、样式统一贴合米色调与主题红。

### 文本与链接

- **基础格式**：粗体、斜体、~~删除线~~、<u>下划线</u>，以及 ==高亮== 强调。
- **链接**：内部链接（如 [本站首页](/tech/tech-overview)）与外部链接（如 [GitHub](https://github.com)）样式各自区分。
- **标题层级**：H1–H6 完整支持，H2–H4 会被自动收录进侧边目录。

### 引用与页边批注

普通 Markdown 引用用细线在正文一侧收束内容，支持多段落与嵌套引用。特色功能是**页边批注（MarginNote）**——把编者按、术语解释、作者判断做成与引文一一对应的出版式单元：

<MarginNote
  label="编者按"
  note="这里不是脱离正文的说明卡片，而是与所引文字一一对应的页边批注；细线标出批注所解释的范围。"
  source="排版示例 · 页边注"
>
  技术写作不仅要把事实说清楚，也要让证据、解释和判断之间的关系一眼可辨。
</MarginNote>

### 列表

- **无序列表**：支持多级嵌套缩进。
- **有序列表**：支持子步骤编号。
- **任务列表**：`[x]` 已完成 / `[ ]` 待办，可直接当清单用。

### 代码

- **行内代码**：如 `console.log()`、`npm install`。
- **代码块**：带语法高亮，已验证 JavaScript、CSS、Bash 三种，其他语言按 Prism 规则自动识别。

```javascript
function greet(name) {
  console.log(`Hello, ${name}!`);
}
```

### 表格与分割线

标准 Markdown 表格直接渲染；`---` 分割线用于章节切分。

### 行内特殊元素

- **键盘按键**：<kbd>Ctrl</kbd> + <kbd>C</kbd> 复制，<kbd>Ctrl</kbd> + <kbd>V</kbd> 粘贴。
- **缩写**：<abbr title="HyperText Markup Language">HTML</abbr> 悬停可看全称。
- **上下标**：水是 H<sub>2</sub>O，质能方程 E=mc<sup>2</sup>。

### 折叠与提示条

- **可折叠块**（details/summary）：默认收起，点击展开补充说明或隐藏代码。

**四种提示条**，语义各有分工，实际效果如下：

<div class="warning">⚠️ **警告**：用于提醒用户注意重要风险。</div>

<div class="note">📝 **注意**：一般补充说明。</div>

<div class="tip">💡 **提示**：技巧与小贴士。</div>

<div class="important">❗ **重要**：必须特别关注的事项。</div>

### 图片

正文图片懒加载、自适应宽度；带图注的图片用 figure 块呈现（图片下方居中说明文字）。

### 数学公式

当前未接入 LaTeX 渲染，公式以纯文本（如 `E = mc²`）展示；如需完整支持，接入 `remark-math` + `rehype-katex` 即可。

## 二、拼音注音组件

`<Pinyin>` 组件给汉字加拼音标注，效果对齐小学语文课本。

### 组件参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `text` | 是 | 要标注的中文文本，一字一个拼音 |
| `pinyin` | 是 | 对应拼音，空格分隔每个字 |
| `yinbiao` | 否 | 逐字声调，支持四种写法混用 |
| `tones` | 否 | 显示模式：`auto`（默认，数字自动转调号）、`symbol`（强制调号）、`number`（强制数字） |

### 声调：四种输入写法 + 五种颜色

`yinbiao` 认四种写法，且可以混用：

| 声调 | 数字 | 中文名称 | 符号 | 英文 | 显示颜色 |
|------|------|----------|------|------|----------|
| 一声 | `1` | 阴平 / 一声 | `¯` | flat | 红 |
| 二声 | `2` | 阳平 / 二声 | `´` | rising | 橙 |
| 三声 | `3` | 上声 / 三声 | `ˇ` | falling-rising | 绿 |
| 四声 | `4` | 去声 / 四声 | `` ` `` | falling | 蓝 |
| 轻声 | `0` | 轻声 | `·` | neutral | 灰 |

<Pinyin text="妈麻马骂" pinyin="mā má mǎ mà" />

### 适用场景

字词、句子、古诗词逐句注音、成语、地名、人名、轻声词、多音字（按语境选音，如"银行 yín háng / 行走 xíng zǒu"）都用同一套写法。

### 实现细节

基于语义化的 `<ruby>` 标签；拼音字号为汉字的六成；响应式自适应；黑白打印时拼音自动转灰；旧浏览器优雅降级。

## 三、响应式目录

目录不是固定挂件，而是按屏幕宽度分三档自适应：

| 断点 | 目录形态 |
|------|----------|
| 宽屏（1400px 以上） | 左侧固定常驻，不随滚动消失 |
| 中屏（768–1400px） | 收进折叠按钮，把正文宽度让出来 |
| 窄屏（768px 以下） | 点按钮全屏展开，半透明遮罩压底 |

### 桌面端能力

- 当前阅读章节**自动高亮**；
- 底部一条**阅读进度条**；
- 点击目录项**平滑滚动**到对应章节。

### 移动端能力

- 右上角折叠按钮唤起；
- 全屏目录、支持触摸操作；
- 点遮罩或按 <kbd>Esc</kbd> 关闭。

### 技术实现

- **自动生成**：扫描正文 H2–H4 标题构建目录树；
- **性能**：滚动监听走 `requestAnimationFrame` 节流，缓存标题位置，只更新必要 DOM；组件卸载时清理监听器；
- **可访问性**：语义化 `<nav>` + ARIA 标签，支持 <kbd>Tab</kbd> 导航、<kbd>Enter</kbd> 选中，屏幕阅读器可朗读状态。

### 规划中

目录内搜索、自定义位置与主题、深层级智能折叠、超长文章虚拟滚动、离线缓存阅读进度。

## 四、工具嵌入组件

正文里可以直接嵌**可交互的小工具**，不跳页面。下面这个计算器就支持键盘操作：

<Tool title="正文里的计算器" description="数字键、四则运算、回车出结果、ESC 清空" collapsible defaultOpen={false}>
  <Calculator />
</Tool>

### 四种用法

1. **直接使用**：只传 `title` + `description`，包裹工具组件；
2. **可折叠**：加 `collapsible`，用 `defaultOpen` 控制初始展开状态；
3. **自定义样式**：传 `class` 挂自定义 CSS 类；
4. **无标题**：不传标题描述，纯嵌入工具本体。

### 组件参数

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `title` | string | 空 | 工具标题 |
| `description` | string | 空 | 描述文字 |
| `collapsible` | boolean | false | 是否可折叠 |
| `defaultOpen` | boolean | true | 初始是否展开 |
| `class` | string | 空 | 自定义样式类 |

### 新增一个工具

往 `src/component/tools/` 放一个新的 `.astro` 组件，在 MDX 里 import 后用 `<Tool>` 包一层即可。组件样式走 Astro scoped 隔离，不污染全局；交互脚本在客户端按需加载，不拖慢首屏。
