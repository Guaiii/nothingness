# Agent 好像没我想的那么复杂

注意审题，我说的是 Agent，不是模型。

先把几种 Agent 的执行步骤拆开看，我想弄清楚提示词、模型调用和工具调用分别放在哪里。

<div class="note">
  <p><strong>草稿说明：</strong>下面是我目前整理的步骤提纲，完整的循环过程和退出条件还需要补充。</p>
</div>

## ReAct 类型的 Agent

我先记下这几个动作：

1. 撰写提示词。
2. 调用大模型。
3. 调用工具。

<details>
<summary>这一节还要补什么</summary>

工具返回的结果怎么接回下一轮模型调用？什么时候继续调用工具，什么时候给出最终答案？这部分还没有写完。

</details>

## PlanAndSolve 类型的 Agent

这一类，我先按“输出计划，再执行步骤”来整理：

1. 撰写提示词，要求模型按规定格式输出步骤。
2. 调用大模型，得到分析结果。
3. 把分析结果整理成待执行的步骤。
4. 循环执行这些步骤。

<details>
<summary>这一节还要补什么</summary>

执行某一步失败后怎么办？是否需要重新规划？这些情况还需要结合具体实现说明。

</details>

## Reflection 类型的 Agent

这一部分，我先把提示词分成三类，分别负责生成、检查和判断下一步：

1. 规范提示词，让输出答案符合约定格式。
2. 检查上一步答案是否还有优化空间，用 `memory` 记录检查结果。
3. 根据检查结果决定是否继续：如果还有优化空间，就把最后一次规范后的输出加入下一轮处理；如果没有，就输出答案。
