# 首页分区为「技术 / 娱乐」，新增 media 集合承载富媒体条目

首页第二个分区由「小说」改为「娱乐」。娱乐是与「技术」并列的**聚合分区**，不是单个集合：它聚合连载小说、单篇随笔与新增的媒体内容。

**决定**：

- 保留 `novel` 集合承载小说与随笔（`isNovel` 区分），URL `/novel/...` 不变。
- 新增 `media` 集合（URL `/media/<slug>`）承载以第三方视频、图片、附件为主体的单篇条目，复用与技术文相同的正文布局。
- 首页「娱乐」标签聚合 `novel`（含此前被漏掉的随笔）与 `media`；技术标签仍只显示 `tech`。
- 搜索、标签聚合、sitemap、RSS、llms.txt 全部纳入 `media`。

原因：把视频/图文/下载塞进「小说」会污染连载模型；新建并列大集合又要改动既有 `/novel/` URL 与已生成的站点地图。聚合分区在不动旧 URL 的前提下容纳新类型（见 `CONTEXT.md` 中「娱乐」「媒体内容」）。
