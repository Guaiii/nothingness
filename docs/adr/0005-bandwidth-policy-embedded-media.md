# 带宽策略：视频只嵌入第三方且点击才加载，图片走内容管线，附件按阈值分流

站点部署在轻量服务器，带宽有限，自托管视频是最大风险。

**决定**：

- **视频**：禁止把视频文件放在本站。仅允许白名单来源（YouTube、哔哩哔哩）以嵌入组件引用，且默认 16:9 响应式、**点击封面后才插入 iframe（click-to-load）**——不点击则不向第三方或本站产生视频流量，移动端也不预载。
- **图片**：放在仓库内，经 Astro 内容资源管线处理（按需尺寸/格式），统一懒加载并由 Nginx 设置长缓存；单图建议控制在数百 KB。
- **附件**：约 10MB 为阈值——小文件放 `public/downloads/` 随站点托管；大文件放对象存储/CDN（OSS/COS/七牛等）或 GitHub Release，正文只放外链。当前没有对象存储时先沿用仓库方案，但大文件不入库。
- Nginx 对 `/_astro/` 与图片/下载类静态资源设置长缓存与 gzip，降低重复流量。

**已否决**：iframe 自动加载（每次打开都拉视频资源）；自托管 mp4（单个视频即可打满轻量服务器带宽）。
