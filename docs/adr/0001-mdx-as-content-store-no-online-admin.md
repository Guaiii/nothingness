# 内容以仓库内 MDX 为唯一事实源，不做在线后台

个人站点，编辑者仅所有者本人，低频长文更新，首要目标是对搜索引擎与 AI 抓取友好，最终部署在自有服务器。曾考虑三种形态：Git 型 headless CMS（Keystatic，GitHub OAuth）、前后端分离（独立 API + 数据库）、单体 SSR。

**决定**：内容的唯一事实源是仓库中的 MDX 文件；在本地 `astro dev` 编辑与预览，不建设任何暴露于公网的在线编辑、登录或写入后端；站点产出纯静态 HTML。

原因：静态预渲染对搜索与 AI 抓取天然最优；单人场景下，鉴权与会话维护、以及“允许公网写入服务器文件系统”是纯负债；`Tool`/`Calculator`/`Pinyin` 等嵌套组件在本地的真实运行预览与线上一致，无需为浏览器编辑器再维护一套组件表单。

**保留的升级 seam**：这放弃了“任意设备通过网页写作”。未来若出现移动端/异地写作或多人协作需求，可在同一批 MDX 文件之上加装 Keystatic，数据无需迁移。
